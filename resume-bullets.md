# FRAME — Resume bullets

- Built a responsive, editorial portfolio site with semantic HTML and CSS Grid, adapting an asymmetrical desktop project archive into a staggered mobile layout.
- Implemented vanilla JavaScript interactions for dynamic project rendering, category filtering, accessible project detail dialogs, navigation state, pointer feedback, and a live color study.
- Added lazy-loaded imagery, IntersectionObserver scroll reveals, frame-coalesced pointer updates, keyboard-operable controls, and reduced-motion support without adding runtime dependencies.
